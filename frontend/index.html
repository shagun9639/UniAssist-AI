Pipeline Architecture

How UniAssist AI Delivers Reliable Answers

1
Student Query

The student asks a question in everyday English via web or mobile.

2
NLP & ML Classification

Text is normalized and classified by a trained Calibrated Linear SVC into one of 20 intents.

3
Knowledge Retrieval

A TF-IDF similarity engine searches verified university FAQs and policy handbooks.

4
Grounded Response

The system returns the exact official answer with source citation or triggers safe fallback.
